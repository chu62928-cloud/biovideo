# Biology-Aware Code2Video

Server source and reproducible experiment records. Code2Video/ is the preserved V1–V4.1 source snapshot; development/v4.2/src/ contains the ongoing isolated V4.2 refactor, not a completed release.

Upstream: https://github.com/showlab/Code2Video (commit 637509294e936b231d220bb555cf74eeedcb9dfd). Preserve its LICENSE and attribution.

Credentials, environments, model caches and rendered videos are intentionally excluded. Full immutable video/trace evidence remains on the server; SHA-256 manifests are included. Configure secrets through environment variables and api_config.example.json.

Current V4.2 work is in progress; do not infer completion from included prototype modules.
