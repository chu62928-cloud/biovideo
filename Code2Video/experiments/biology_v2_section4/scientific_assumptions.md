# 科学假设与简化边界
- 统一坐标：复制叉向右，上模板左3′右5′，下模板左5′右3′；新前导链向右延长，后随链每片段向左延长。坐标约定不是分子真实朝向。
- 真核起始包含primase/Pol α交接。本节将“形成RNA部分”和随后DNA延长抽象分开，短DNA起始段及Pol α→Pol ε/δ交接不逐个呈现；不宣称引物只由孤立引物酶完成全部起始步骤。
- 引物加工存在多条路径。用“RNA processing”统称，不把RNase H当作唯一机制；Pol δ/FEN1等中间细节不逐一绘制。必须保留RNA去除→DNA补缺→DNA切口连接的因果顺序。依据 https://www.nature.com/articles/s41467-022-34751-2 。
- 聚合酶、引物酶、连接酶均为示意图标，不是真实蛋白质结构，不表达原子尺度或真实速度。颜色是辅助，身份靠形状、注册ID与短标签共同维持。
- 复制叉保持连续，仅展示一个局部；不扩展端粒、多个起点、染色质等其他节内容。
- 标签简化与核苷酸数目不代表真实片段长度。几何监测只能检验表现关系，不能替代生物学专家判断。
