# BioVideo V4.3.3 实验总结

本轮检验两个问题：结构化工具能否帮助模型完成科学返工，以及已审核的机制能否驱动可核查的英语教学片段。科学状态为 SCIENCE_PARTIALLY_VALIDATED，视频状态为 VIDEO_CANDIDATE_DELIVERED。

## 工程与实验

原始 Code2Video 从分镜生成动画代码。本实验沿用证据定位、类型化科学模型、独立审核、场景规划与运行轨迹，增加四阶段建模和按目标限定的编辑工具。模型提出语义修改，程序检查主目标、关联目标、可编辑字段及原文证据。预检通过后可进入原有事务的因果和独立审核流程。分阶段生成使用 DeepSeek 的 JSON 对象模式及本地模式校验。冻结版本 d521fda443963cf24f3ae4d85e346e2bba39a828。

教学任务 → 证据与阶段建模 → 编辑授权与预检 → 候选模型及独立审核 → 场景与 Manim → 实际轨迹与视频复核。

主要改动在 src/biology_expert 下的 staged_model.py、typed_science_builder.py、repair_harness.py、model_repair.py、providers.py，以及 src/gpt_request.py。实验驱动直接调用现有组件，既有智能体默认入口仍使用旧建模方法。局部依赖以可编辑对象为节点，尚未把参与角色、证据主张和可观测条件全部建成独立节点。预检可合并多项权限错误，底层结构校验仍可能停在第一个错误。失败案例中的实质科学事务没有到达独立审核。

| 阶段 | 结果与限制 |
|---|---|
| 离线回归 | 104 项历史测试和 18 项新增测试通过。三个历史非法补丁重放均被拒绝。旧测试目录混用导致的一次收集失败另存。 |
| 配对编辑 | 两组各两个请求，每批六题。10 个合法任务以恢复原字段为判据，直接 JSON 得 8，新工具得 6。两个禁止操作均未提交。副本中成功恢复原值也可能恢复原有科学问题，因此该分数只衡量编辑。 |
| 骨骼肌 | 使用历史独立审核及其已检索正文。两个提案在预检被拒绝，出现扩展目标及新增实体引用错误。0 个科学修复获批。 |
| 未见主题 | 冻结后提交瞳孔对光反射。实际检索后，第一阶段经过一次局部纠正仍将实体数量写为文字。未进入独立科学审核。 |
| 视频 | 使用历史批准的限定有丝分裂机制。新渲染 24 秒，1280×720，24 帧/秒，英语字幕。开发者调整时长、教学字幕与示意图，并依据首轮视频审核修正染色单体弯折方向。无新增科学模型获批。 |
| 后端对照 | Wan 和 Seedance 均为无首尾帧预演。Wan 请求通过本地校验，Seedance 配置未通过。真实生成费用和跨模型视觉比较均无数据。 |

## 视频与审核

下载 videos/CANDIDATE_mitosis.mp4；对照图 videos/keyframes.jpg。OpenStax 图 10.8 的图注及替代文字用于区分动粒、小臂与纺锤丝附着位置，使用原创示意几何。未复制外部图片。模型、场景、视频与压缩轨迹的哈希见 video_manifest.json。场景复用了已有模型与场景绑定，此回归没有从新任务自主生成整部视频。

实际运行检查有 1 项完整通过、3 项部分验证。首版审核指出后期动粒拖在后面。修改后，第二轮千问审核认可 12–23 秒分离方向；仍在 0–2 秒报告右侧附着不清，在 3–7 秒报告标签重影。确定性轨迹能验证端点，视觉模型的时间定位是审核意见，未经独立逐帧人工确认。最终科学与视觉审核均要求修改。未开展学生观看实验。

## 消耗与复现

本轮 DeepSeek 9 次、千问 2 次，共 56,650 个输入和 11,254 个输出 Token。金额未返回。项目适合作为可追溯的工具调用、失败拦截和候选片渲染演示，暂不支持科学智能体进入稳定维护。
