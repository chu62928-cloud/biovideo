# V4 实验协议
日期：2026-11-24，北京时间。研究假设尚待验证。

目标是在 Planner 与 Coder 之间加入科学场景中间表示、可编辑组合与状态转移，检验结构连续性及返工可控性。

A0 引用冻结的 V3 未批准候选，不调用模型或重渲染。A1 使用有身份和关系的组合，执行过程中不启用完整前后置条件。A2 复用 A1 的同一模型计划、蓝图与组件，启用完整条件。两者均保留事后轨迹验证；这是验证强度对照，合法输入下可能产生相同视频，不能据此声称错误率下降。A3 从 A2 的实际成功版本开始，审核后进行受边界约束的真实返工；根本结构问题返回结构层，不能靠布局掩盖。B1 复用同一核心与适配器，使用有丝分裂知识、组合与过程数据。

冻结：原始第4节五个事件、知识包来源、组合蓝图、原有接口、同一 DeepSeek 配置、854×480/15帧、Manim 0.19 和沙箱执行。允许变化：模型生成的短标题与分镜计划、组间验证模式、受任务约束的返工表示。DNA 目标30秒，有丝分裂目标12秒。

模型使用现有环境变量配置及原有接口默认采样，不打印密钥。V4独立请求上限 DeepSeek10/Qwen3；不调用Wan或Seedance。持久账本在调用前记录请求，API失败后停止新增请求。无更高层金额接口可查询，金额未知，不能以调用次数代替费用。

执行顺序：离线测试→真实DNA计划与IR审核→A1/A2 Coder及完整渲染→A2全视频科学审核→A3受控返工和再验收→B1。IR未通过时只允许标注为诊断候选的渲染，不标记正式科学批准。

生成教学代码来自真实Coder；通用适配器和两主题组合/过程蓝图属于人工工程准备。代码可能是调用可信组件的薄封装，该实验证实的是受约束编译路径，不是模型自行发现完整科学动画。必须分别归因。

每组一个样本，统计均为描述性计数，无显著性检验。科学约束通过率分母为实际获得PASS或FAIL的检查；不确定、未测和异常另列。几何标签重叠为抽样启发式计数，不能等价于观众感知。真实观众研究未执行。

工程成功要求完整渲染、完整解码、代码视频轨迹哈希配对。科学批准还要求IR审核通过、必要实际检查通过、完整视频科学审核通过及无新增关键错误。工程成功与科学批准分别记录。失败候选与回滚前版本均保留，每问题最多两次修复，不为耗尽额度重复请求。
