# BioVideo V5 正式实验

V5_AGENT_PARTIALLY_VALIDATED。五个冻结后提交的正式请求中，三个取得通过隔离审核的事实表，一个生成可播放视频，零个取得科学与视觉批准。三个视频文件包括一段 V5 研究候选及两段原始 Code2Video 对照作品。关键帧总览为 keyframes.jpg。

## 自主性与科学验证

统一入口 generate_biology_video.py 调用既有 BiologyExpertAgent.generate_video。模型选择检索、事实核验、分镜、严格建模、渲染审核、场景修复或结束。程序负责权限、引用、逐段缓存、渲染隔离、费用调用次数与审核门禁。开发任务为有丝分裂，因决策协议失败而停止，随后修正控制器并冻结源码。正式生产代码提交 719b38a2dfcb624750e5daf27648f7ec3730992a。冻结后未修改通用源码或科学字段。

已有教材检索、原文支持检查、分阶段建模、状态校验和模型网关被接入。事实核验可以独立支持分镜。严格模型被选中后，多次耗尽剩余请求，说明可选工具在实际运行中仍能阻塞交付。尚未实现贯通的运行时科学契约编译。模型选择验证类别，逐场景保存对象实际起止位置，千问检查实际成片。教学目标覆盖、事实支持与像素审核有各自的证据。数目未知的集合使用 unspecified_collection，不转换为具体数量。本轮绘图使用声明式图形与平移动画，没有人工编写正式主题动画。

## 五个正式请求

| 主题 | 实际结果 |
|---|---|
| 红细胞形状与氧运输 | 事实和分镜生成。选择严格建模后因格式错误和预算停止。 |
| 水分跨膜移动与植物细胞坚挺度 | 生成并解码 24 秒英语视频。独立审核指出水浓度标签与流向冲突、膨压箭头含义不清和标签重叠。修复调用未提供有效观察引用。 |
| 酶与底物 | 事实与分镜生成。严格建模失败后停止。 |
| 感觉受体信号转换 | 首次教材地址返回 404，模型更换地址后成功获取证据。事实审核未通过，严格模型未完成。 |
| 气孔与水分流失 | 教材网址反复返回 404，依停止条件结束。 |

真实任务能观察到一次检索恢复，零个获批的场景返工。四个模拟反事实中，渲染错误和局部审核错误改变了所选工具；另两个未改变。行为探针以批量独立请求模拟，只测试选工具，未完成同预算固定工作流的可执行配对。三类有效反事实的验收条件未达到。所选教材图注和替代文字进入分镜请求，没有两个新主题的成片证明专业视觉参考改善了画面。正式任务冻结后揭示；其中植物渗透在任务书示例中已出现，不计作严格保密未见题。

## 对照、成本与限制

原始 Code2Video 的 Planner/Coder 使用相同需求、模型和 24 秒目标，运行两组基线，由受限环境渲染。红细胞成片 13.27 秒，植物细胞成片 35.93 秒。两片的独立模型审核科学与视觉均为 PASS。对照驱动首次选中了无动画的基类，保留驱动失败记录后改为渲染带 construct 方法的场景。基线审查提示和请求预算与 V5 存在差异。此对照未支持 V5 性能提升。

全轮 DeepSeek 60 次，千问 3 次。输入 192618、输出 56908 Token。无实际金额账单。只实施了请求计数限制，未实现独立实时金额和累计 Token 硬限。Wan 与 Seedance 仅预演。历史测试 122 项通过。复现时先配置既有环境变量及服务器渲染隔离器，正式实验由 formal.py 调用同一个 CLI。断点恢复按成功工具和持久化产物执行，未验证渲染或模型调用中途断电后的精确恢复。
