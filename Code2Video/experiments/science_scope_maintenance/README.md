# 科学范围补丁通用维护

依据V4.3.2完成性审计已复现的接口表达限制，新增受约束scope_patch。只有修复任务显式指向scope且issue_id匹配，才可更正included_processes/excluded_processes/simplifications；保留所有原included过程，不许新增excluded过程，不许改变物种、主题、观众。引用须是可定位原文正文；候选仍经过Schema、因果检查和独立科学审核，门禁未降低。

该改动是通用表达能力修复，不是主题答案补丁。修复任务规划器可根据SCOPE_MISMATCH赋予scope目标。原V4.3.2三主题均达到尝试上限，未重跑、不覆盖。没有新LLM或视频调用，不把合成测试通过当科学模型修复成功。新版尚需独立评测，不能宣称Science稳定。

当前保守限制：仅允许移除过时排除项或添加包含项，更名/删除原包含过程均拒绝；语义是否偷偷缩小范围仍依赖原始任务的独立复核，字符串保留并非充分证明。支持摘录只校验真实性，不代替蕴含判断。
